# TongCraft Map：产品意图与首版范围

**状态：维护者于 2026-11-20 确认的产品设计，不是已上线功能清单。**

这张地图回答两个问题：**“上次导出存档时，这里是什么样？”“我要找的机器在哪？”** 它服务于已有的使用习惯：维护者定期导出世界，玩家从官网或别人分享的链接查位置。更换 BlueMap 是为了自己掌控制图和浏览体验，不是为了改变玩家找机器的方式。

## 维护者：先制图，检查后再上线

维护者在独立的桌面制图客户端（不是游戏启动器）里选择世界存档、维度和输出目录，开始制图、查看进度，必要时取消。沿用现有的定期导出方式，不要求改造 Fabric 游戏服务器，也不要求安装地图模组。

地图生成后，维护者先预览玩家将看到的版本：找一台熟悉的机器，核对标记是否对准建筑；切到下界，检查展示的层是否符合服务器的实际用途。**生成成功不等于同意上线。** 只有确认后才发布；制图中、取消或检查不通过，都不能让玩家失去上一版地图。是否提供一键发布尚未决定。

## 玩家：从已有链接找到地方

玩家只需要浏览器。网页提供主世界、下界、末地的二维地图，可以平移、缩放、查找机器、查看坐标，也可以复制位置链接分享。最重要的入口不一定是地图首页：有人在官网机器列表点地图按钮，也有人打开群里以前发过的链接。两者都应该直接到正确维度和位置，不需要重新搜索，也不需要知道 BlueMap 已被替换。

## 首版验收与非目标

端到端验收：用一份真实快照制作地图 → 维护者在本地预览并确认一台已知机器 → 发布 → 玩家从官网现有链接打开新地图，在正确维度看到与预览一致的地形和机器位置。另检查取消一次未完成的制图后，公开站仍可浏览上一版。

首版不是实时地图：不追踪玩家，不即时展示刚建好的建筑，不提供 3D 自由飞行。GPU 只用于可选的离线制图加速；它不是玩家访问网站的前提，也不是判断地图是否正确的标准。

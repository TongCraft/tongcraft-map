## 边界与连线

- 实线（数据流）：只读世界快照 → 共享渲染核心 → 待发布地图；待发布地图向上 → 客户端预览；待发布地图向右跨区 → 玩家网页，标注「确认后发布」。这是发布后的数据流，不是公开网页读取本地文件。
- 虚线（控制）：制图客户端 → 共享渲染核心；CLI → 同一个共享渲染核心。
- CPU 基线与 GPU 可选是核心内的并列后端，不互连。世界快照、渲染核心和预览留在本地。

# TongCraft Map

把定期导出的 Minecraft 世界快照做成二维网页地图，让玩家找到服务器里的机器和建筑。项目目标是替换 TongCraft 现用的 BlueMap 平面地图，沿用 Fabric 服务器的存档导出流程，并保留 `map.weiuou.top` 上已有的坐标链接。无需在游戏服务器安装地图模组。

**当前处于设计阶段。** 桌面制图客户端、渲染 CLI 和新地图网站尚未实现，本仓库暂无安装或运行命令。

## 首版怎么用

- **维护者**在独立的桌面制图客户端选择只读快照、维度和输出目录，查看制图进度，必要时取消。先在本地预览一台已知机器的位置，再单独确认发布；制图中、取消或预览未通过时，玩家仍能打开上一版地图。是否提供一键发布尚未决定。
- **玩家**用浏览器查看主世界、下界和末地，平移缩放、查找机器、查看坐标并分享位置。从官网机器列表或旧链接进入时，地图应直接打开对应维度和位置。

地图反映的是上次发布的快照，不追踪实时玩家，也不提供 3D 自由飞行。公开站点只提供静态地图产物和允许公开的标记，不提供原始世界存档。

参与开发前请读[协作约定](AGENTS.md)。私有世界快照放在仓库外或已忽略的 `snapshots/`，本地渲染产物放在 `output/`，不要把这些文件提交到仓库。
